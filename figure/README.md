# Figures

This folder contains the figures generated by `lysosomal_enzyme_analysis.r` for human TPP1.

* `TPP1_amino_acid_composition.png`: Figure 1, bar chart of the amino acid composition of TPP1.
* `TPP1_potential_N_glycosylation.png`: Figure 2, positions of the 5 potential N-glycosylation motifs (N-X-S/T, where X is not proline) along the 563-residue protein.

NCBI RefSeq accession: NP_000382.3
NCBI record: https://www.ncbi.nlm.nih.gov/protein/NP_000382.3
