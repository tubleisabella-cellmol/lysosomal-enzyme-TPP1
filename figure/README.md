# Results

This folder contains the output tables generated by `lysosomal_enzyme_analysis.r` for human TPP1.

* `TPP1_summary.csv`: protein length (563 amino acids) and number of potential N-glycosylation motifs (5).
* `TPP1_amino_acid_counts.csv`: count and percentage of each of the 20 amino acids. The most common are leucine (11.19%), serine (10.30%), glycine (9.41%), proline (7.82%) and valine (7.28%).
* `TPP1_motif_positions.csv`: position and sequence of each potential N-glycosylation motif (N-X-S/T, where X is not proline): 210 (NLT), 222 (NNS), 286 (NIS), 313 (NES) and 443 (NAS).

NCBI RefSeq accession: NP_000382.3
NCBI record: https://www.ncbi.nlm.nih.gov/protein/NP_000382.3
