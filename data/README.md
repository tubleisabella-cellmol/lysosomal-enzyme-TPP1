# Data

This folder contains the human TPP1 protein sequence downloaded from the NCBI Protein database in FASTA format.

* `TPP1.fasta` — contains the protein sequence used for the amino acid composition and potential N-glycosylation motif analysis.

NCBI RefSeq accession: NP_000382.3
NCBI record: https://www.ncbi.nlm.nih.gov/protein/NP_000382.3
